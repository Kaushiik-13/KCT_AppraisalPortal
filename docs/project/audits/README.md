# AFPI — Project-wide audit register

This directory is for **new** cross-module, shared-schema, integration, security, system-level and release-readiness audits for the production-oriented implementation. Module-owned audits belong to `docs/modules/<module>/audits/`.

## Current audits

No production-oriented project-wide audits have been recorded yet.

For new work, copy [AUDIT-TEMPLATE.md](AUDIT-TEMPLATE.md) to `YYYY-MM-DD-topic.md`, then register the report here with date, baseline commit, findings status and follow-up Issues.

## Ownership and history

Project audits require a separately authorized documentation branch and PR. Prior PoC audits and verification records are retained only in the [legacy archive](../../reference/legacy/README.md); they are historical evidence, **not** current implementation verification.
