# Archived web proof of concept

This is the former Next.js proof-of-concept application, preserved for reference. It is not the new AFPI application and must not be treated as the production architecture or workflow source. The maintained product requirements live in the repository-level `docs/` folder.

The previous UI, Next.js route handlers, fixtures, and tests remain together here so their behavior can be studied without mixing them into `apps/web`. To run this archived prototype locally, install its dependencies from this directory first; it is separate from the root workspace.
