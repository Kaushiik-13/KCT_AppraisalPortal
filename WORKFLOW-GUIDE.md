# Workflow guide

The maintained guides are now organized under `docs/`:

1. [User guide](docs/USER-GUIDE.md): inputs, blocks, testing, saving, and reset.
2. [Publication KPI walkthrough](docs/PUBLICATION-KPI.md): the original twelve-step example, sample paper, mappings, scoring, and appraiser review.
3. [Training KPI walkthrough](docs/TRAINING-KPI.md): create a generic workflow and policy from scratch.
4. [Scoring](docs/SCORING.md): distinguish publication scoring from standalone Result policies.
5. [AI instructions and API](docs/AI-AND-API.md): use a custom AI purpose on any path.
6. [Troubleshooting](docs/TROUBLESHOOTING.md): resolve setup, source, storage, and provider issues.

One submission flows through the connected steps; twelve nodes do not mean twelve papers. Draft configuration autosaves, but test files, values, and review decisions remain session-only.

See the [complete documentation index](docs/README.md) for architecture, models, extension guidance, tests, decisions, and remaining work.
